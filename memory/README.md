# Memory wiki index

Notes for agents who work on this repo. Each page covers one topic.
Read the pages that match your task. Update them as you learn.

| Page | Read it when |
| --- | --- |
| [architecture.md](architecture.md) | You need to know how the packages fit together, or how plugins and the `Test` class work. |
| [packages.md](packages.md) | You need to find which package owns a feature. |
| [workflow.md](workflow.md) | You set up, build, test, snapshot, format, or build docs. |
| [conventions.md](conventions.md) | You write code, tests, commits, or change dependencies. |
| [release.md](release.md) | You touch versions, changelogs, or publishing. |
| [gotchas.md](gotchas.md) | Something fails in a way that makes no sense. |
| [decisions.md](decisions.md) | You need to know why the user chose something. Add new decisions here. |

## How to write a note

- One fact or rule per bullet. Put the reason next to it when the
  reason is not plain.
- Give file paths so a reader can check the note against the code.
- Write dates as `YYYY-MM-DD`.
- Mark a note `(unverified)` if you inferred it and did not check
  it.
- If a note is wrong, fix it. Do not leave old and new versions side
  by side.
